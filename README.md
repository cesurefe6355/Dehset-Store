# 🛒 Dehşet Store

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-Apache%202.0-red.svg)
![Status](https://img.shields.io/badge/status-live-brightgreen.svg)

**Dehşet Store**, dijital ürün ve oyun hizmetlerinin hızlı, güvenli ve modern bir arayüz üzerinden sunulması amacıyla geliştirilmiş web tabanlı bir e-ticaret platformudur.

🌐 **Canlı Site / Live Demo:** [dehsetstore.rf.gd](http://dehsetstore.rf.gd)

---

## 🚀 Özellikler

- 📱 **Tam Sorumlu (Responsive) Tasarım:** Masaüstü, tablet ve mobil cihazlarla tam uyumlu kullanıcı arayüzü.
- 🔐 **Kullanıcı & Yönetim Paneli:** Güvenli oturum yönetimi, yetkilendirme ve admin kontrol imkanları.
- ⚡ **Hızlı Ürün Listeleme:** Kategorilere ayrılmış, filtrelenebilir dinamik ürün katalogları.
- 🛠️ **Yönetilebilir Veritabanı:** Ürünler, siparişler ve kullanıcı verilerinin dinamik takibi.

---

## 🛠️ Kullanılan Teknolojiler

Proje geliştirilirken kullanılan temel teknolojiler:

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
